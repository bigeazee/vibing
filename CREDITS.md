# Credits

## Art

All sprite art in this project comes from **Kenney** — <https://kenney.nl>.

Kenney releases these packs under **CC0 1.0 Universal (public domain dedication)**, so no
attribution is legally required. We credit them anyway, because the work is excellent and
free art deserves naming.

| Pack | Source |
|---|---|
| Tiny Town | <https://kenney.nl/assets/tiny-town> |
| Tiny Dungeon | <https://kenney.nl/assets/tiny-dungeon> |

> **Note:** the packs in `/assets/` have been pruned to the files this project actually
> uses — the packed tile atlases and the pack licence files. The full packs contain many
> more individual sprites and are worth downloading directly from Kenney if you are
> extending the map.

If you add art from any other source, check its licence first and add it to this file.

## Everything else

Game code, map design and station content are original work for this project.

The visual style is a homage to top-down 2D adventure games of the late 1980s and early
1990s. No proprietary art, music, character names or trademarks from any commercial game
are used or referenced anywhere in this repository.
